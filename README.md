Hello!! This is a Pure Physics based puzzle game, Download the zip file and extract, then run the exe inside the extracted folder to play.

None of these solutions require pixel perfect timing or accuracy. Half the puzzle is figuring out how to set up a solution you have, or making your current solution a little bit better or easier. With optimal strategy, I beat this game on a trackpad that doesn't respond half the time, but don't play with a trackpad it's really hard.

There are no hidden items, and nothing that is placed in any level is useless. The puzzles are derived purely from the physics of the game, so theoretically you could jump to the last level and solve it by just messing around. I would recommend you don't do that though, as the last level is pretty difficult.
